# Data Jobs Analysis in Excel

This repository contains two Excel projects exploring data-related job postings, salaries, and the skills employers request. The work uses Excel tables, summary analysis, and dashboard views to make job market patterns easier to explore.

## Projects

### 1. Data Jobs Dashboard
**File:** `Project 1 - Final Dashboard.xlsx`

<img width="1757" height="847" alt="Screenshot 2026-10-31 160330" src="https://github.com/user-attachments/assets/a7d5408a-ca21-413a-b6dd-55a7015f596c" />

An interactive dashboard built from a job-postings dataset. The workbook includes 32,672 posting rows and fields such as job title, location, work arrangement, schedule, employer, posting date, salary, and listed skills.

Workbook sheets:

- `Data` — source job-posting records
- `Data Validation` — supporting values for consistent categories
- `Title`, `Country`, `Type`, and `Platform` — supporting breakdowns used in the analysis
- `Salary Dashboard` — dashboard view of job and salary patterns

A focused comparison of skills, job roles, and salary measures. Its worksheets summarize skill demand by job and compare median salary across roles, locations, and skills.

Workbook sheets:

- `Skill_Job_Analysis` — skill likelihood / frequency by job role
- `Salary vs Skills` — salary comparisons for selected skills
- `Salary analysis` — salary summaries by job and geography

## How to explore

1. Download or clone this repository and open either `.xlsx` file in Microsoft Excel.
2. Use the dashboard controls, filters, and slicers where available to narrow the summaries.
3. Compare roles, locations, and skills across the two workbooks. Salary figures and job-posting patterns describe the dataset included in the files and may not represent the entire labor market.

## Skills demonstrated

- Cleaning and organizing job-posting data
- Data validation and categorical summaries
- Analyzing salary and skill demand by role
- Building Excel dashboards and interactive views
- Communicating findings through charts and summary tables
